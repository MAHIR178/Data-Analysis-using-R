Retail Sales Analysis Using Tidyverse

This project analyzes retail sales data using R and the Tidyverse to identify sales and profit trends, regional performance, and product category performance.

What I Did

Cleaned and prepared 6,036 sales records, removing duplicates and invalid records.

Calculated key performance indicators including revenue, profit, average order value, profit margin, and return rate.

Analyzed monthly revenue and profit trends.

Compared revenue across different regions.

Analyzed revenue, profit, and profit margin by product category.

Created visualizations using ggplot2 to present the findings clearly.

Key Findings

Total revenue: $1,094,641

Total profit: $353,198

Average order value: $182.44

Profit margin: 32.3%

Return rate: 5.0%

East generated the highest revenue.

Furniture generated the highest total profit.

Office Supplies had the highest profit margin at 40.9%.

Tools Used

R, Tidyverse, dplyr, ggplot2
